# Colores y branding Nacho Racing

## Paleta base (tomada del logo)
| Token | Hex aprox. | Uso |
|---|---|---|
| `--nr-red` | #FF3131 | Letra N. Acción, energía, acentos, CTA secundario, detalles de velocidad |
| `--nr-blue` | #2038C8 | Letra R. Confianza, técnica, enlaces, CTA principal no-WhatsApp |
| `--nr-blue-deep` | #1A3FA0 | Esquina inferior del degradado. Fondos de sección "confianza" |
| `--nr-white` | #FFFFFF | Centro del degradado. Respiro, elegancia |
| `--ink` | #0A0C10 | Fondo oscuro elegante (no negro puro) |
| WhatsApp | #25D366 | Solo el botón de WhatsApp |

El degradado diagonal rojo→blanco→azul del logo es un recurso de marca: usarlo con moderación (líneas, bordes, transiciones), no como fondo de toda la página.

## Reglas
- Proporción aproximada: 70 % neutros (oscuro/blanco), 20 % azul, 10 % rojo.
- Rojo = acción/emoción; azul = confianza/seguridad. No usar rojo para errores masivos ni bloques grandes de texto.
- Contraste mínimo AA (4.5:1 texto normal). Verificar rojo sobre oscuro y azul sobre oscuro (el azul #2038C8 sobre negro NO pasa para texto: aclarar a ~#5B7CFF para texto).
- Tipografía: display condensada e itálica/inclinada que eco del logo (inclinación de las letras NR) + sans limpia para lectura.
- Elegancia = espacio en blanco, pocas fuentes, fotos bien recortadas, nada de sombras pesadas ni gradientes arcoíris.
